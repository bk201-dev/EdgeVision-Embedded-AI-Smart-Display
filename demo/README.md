# Demo

This folder contains the files used to reproduce the end-to-end demonstration.

## Recommended demo

1. Start the camera.
2. Run local inference.
3. Produce a class and confidence score.
4. Convert the result to a `content_id`.
5. Send the `content_id` to the embedded controller.
6. Update the display.

Use `content_map.example.json` as a starting point.
